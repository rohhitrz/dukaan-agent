# Returns Window

- Customers may request a return within **7 days** of the delivery date.
- Apparel and footwear have a **14 day** return window.
- Perishables, innerwear, and earphones are **not returnable** for hygiene reasons.
- Returns outside the window require human approval - escalate them.
- The item must be unused and in original packaging, except for damaged-on-arrival items.
